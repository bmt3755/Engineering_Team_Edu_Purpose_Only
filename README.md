## Project Overview

This project utilizes **CrewAI** to simulate a full-cycle software engineering team. A squad of specialized AI Agents collaborates to take a raw requirement (a Trading Simulation Account System) and autonomously delivers a fully functional Python backend, a matching Gradio frontend, and a comprehensive unit test suite.

## Team Architecture

The system operates as a sequential pipeline where each agent's output becomes the context for the next:

1. **Engineering Lead (GPT-4o):** Analyzes the requirements and architects a detailed technical design, defining class structures and method signatures.
2. **Backend Engineer (Claude 3.7):** Translates the design into a self-contained, efficient Python module (`accounts.py`).
3. **Frontend Engineer (Claude 3.7):** Reads the backend code and generates a functional web UI (`app.py`) using **Gradio** for immediate user interaction.
4. **Test Engineer (Claude 3.7):** Analyzes the backend logic and writes a complete `unittest` suite to verify functionality and edge cases.

## Key Features

* **Multi-LLM Orchestration:** Demonstrates how to mix models for specific tasks (e.g., GPT-4o for high-level architecture, Claude 3.7 Sonnet for precise coding).
* **Full Stack Generation:** Automatically produces both the logic layer (Backend) and presentation layer (Frontend).
* **Quality Assurance:** Includes an autonomous testing step to ensure code reliability.
* **Safe Execution:** Agents are configured with Docker execution modes to safely run and verify code generation (optional configuration).

## Installation & Setup

1. **Clone the repository**
```bash
git clone https://github.com/YOUR_USERNAME/Engineering-Crew.git
cd Engineering-Crew

```


2. **Install dependencies**
```bash
pip install -r requirements.txt

```


3. **Set up Environment Variables**
Create a `.env` file in the root directory and add your API keys:
```env
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...

```


4. **Run the Crew**
```bash
python main.py

```


5. **View the Results**
After the crew finishes, check the `output/` directory:
* `accounts.py`: The generated backend logic.
* `app.py`: The generated frontend UI.
* `test_accounts.py`: The unit tests.


**To run the generated app:**
```bash
python output/app.py

```

## ⚙️ Customization

You can change the software requirements in `main.py` to build different tools. Just update the `requirements` string:

```python
requirements = """
A simple To-Do list manager that allows users to...
"""

```

The crew will automatically adapt the Architecture, Code, UI, and Tests to match your new request.
